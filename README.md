## 🌟 نبذة عن المشروع
منصة واستوديو **بُـنْـيان** تجمع بين فنون العمارة السلمانية والنجدية المعاصرة وأحدث الحلول الرقمية التفاعلية:
1. **حاسبة تكاليف البناء والتشطيب الذكية (Smart Construction & Finishing Cost Estimator):**
   - حساب فوري لمسطحات البناء (BUA) وتكلفة المتر المربع التقديرية بدقة 98% لمناطق المملكة (الرياض، جدة، أبها، الدمام، نيوم).
   - تقسيم مالي دقيق لسبع مراحل هندسية متوافقة مع الكود السعودي:
     - الحفر والأساسات والهيكل الإنشائي (SBC 301 / 304).
     - العزل المائي والحراري المعتمد (SBC 601 / 602).
     - التمديدات الكهروميكانيكية والتكييف المخفي VRF (SBC 401 / 801).
     - الأرضيات ورخام ستتواريو وبورسلان إسباني (SBC 1001).
     - الواجهات الحجرية السلمانية والزجاج المزدوج (SBC 201).
     - الأبواب الخشبية المصمتة والأسقف الديكورية والجبس الفرنسي.
     - الأنظمة الذكية والمصاعد وشبكات الري واللاندسكيب.
   - ترقيات وأنظمة ذكية: أتمتة KNX الألمانية، مسبح إنفينيتي مدفأ، مصعد بانورامي هيدروليكي، طاقة شمسية كهروضوئية 15kW، فناء نجدي مع نظام ضباب، وقاعة سينما معزولة صوتياً وسبا.

2. **استوديو الإضاءة والخامات التفاعلي (Interactive Room Lighting & Material Moodboard Studio):**
   - محاكاة فيزيائية حية لصالة معيشة ملكية بنوافذ بانورامية وأثاث إيطالي فاخر.
   - 4 درجات حرارة ضوئية: (2700K دافئة، 3500K شمس الأصيل، 5000K إضاءة معارض، وإضاءة مخفية ليلية Cove LED).
   - خامات أرضيات: رخام ستتواريو إيطالي، ترافرتين سعودي، باركيه جوز أمريكي شيفرون، مايكروسمنت عصري.
   - كسوات جدران: حجر الرياض المنحوت، جص فينيسي، شرائح خشب بلوط عازلة للصوت، وألواح نحاس مسحوب.
   - مؤشر التناغم المعماري اللحظي ومعدل الامتصاص الصوتي (NRC) والتكلفة لمساحة 50م².

3. **أطلس الطرز المعمارية السعودية والعالمية (Saudi Style Atlas):**
   - العمارة السلمانية المعاصرة (الرياض).
   - فيلا الفناء النجدي الحديث (الدرعية).
   - أجنحة الحجر العسيري والضباب (أبها).
   - قصر الكثبان الساحلي (أمالا والبحر الأحمر).
   - الحداثة الزجاجية المينيمال الكابولية.
   - الرواشين الحجازية المطورة (جدة).
   - تحميل مباشر لأي طراز داخل حاسبة التكاليف بضغطة زر.

4. **مولد جدول الكميات وعرض السعر المعتمد (Official Engineering BOQ Modal):**
   - جدول كميات معتمد متوافق مع كود SBC يتضمن تفقيط الأسعار، ضريبة القيمة المضافة 15%، ختم الاعتماد الرقمي برقم مرجعي، وشروط الضمان (10 سنوات إنشائي، 5 سنوات عزل، سنتان كهروميكانيكي).
   - إمكانية الطباعة الرسمية النظيفة (Print-optimized `@media print`).

5. **محرك المؤثرات الصوتية والسينمائية (Cinematic Motion & Web Audio API):**
   - تفاعل بصري 3D Tilt مع تسليط ضوء ديناميكي على البطاقات.
   - خلفية شبكة مخططات معمارية (Blueprint Canvas) وجزيئات غبار ذهبية تتفاعل مع حركة الفأرة.
   - مؤثرات صوتية هندسية رقيقة عبر Web Audio API مع إمكانية الكتم.
   - احتفال Confetti بألوان الذهب والأزرق السماوي.

6. **نظام الثنائية اللغوية والسمات (Bilingual AR/EN & Dark/Light Theme):**
   - دعم كامل للغتين العربية (افتراضياً RTL) والإنجليزية (LTR).
   - تبديل سلس بين الوضع الليلي الفاخر (Obsidian Studio) ووضع النهار العاجي (Daylight Ivory Blueprint).

## 🛠️ البنية التقنية (Tech Stack)
- **Engine & Bundler:** Vite 6 + TypeScript 5
- **Animations & Physics:** GSAP (GreenSock) + Canvas-Confetti
- **Audio Synthesis:** Web Audio API (Procedural Oscillators)
- **Styling Architecture:** Modern CSS3 Custom Properties + Liquid Glassmorphism + 3D Transforms
